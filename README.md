# Kenya Dating Match

Location-based online dating platform for people in Kenya.

## Features
- User registration/login via Netlify Identity
- Profile setup with GPS location
- Nearby matching based on coordinates and county
- Potential for chat, photo uploads (Netlify Blobs), reports, M-Pesa

## Tech
- Frontend: React + Vite
- Backend: Netlify Functions
- Database: Netlify Database (Postgres)
- Auth: Netlify Identity
- Hosting: Netlify + GitHub

## Setup
1. Enable Netlify Identity in dashboard
2. Deploy to Netlify
3. Database migrations run on deploy

Live: https://kenya-dating-match.netlify.app
